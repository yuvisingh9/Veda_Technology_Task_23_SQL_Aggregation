# Task 23: SQL Aggregation Basics

## 📌 Project Overview
This project demonstrates the use of SQL aggregate functions to analyze and summarize retail order data. It focuses on calculating totals, averages, minimum values, maximum values, and grouped summaries.

## 🎯 Objective
To understand and implement SQL aggregate functions:
- COUNT()
- SUM()
- AVG()
- MIN()
- MAX()

## 🛠️ Tools & Technologies
- MySQL
- PostgreSQL
- SQL

## 📂 Project Files
- `Task_23_SQL_Aggregation.sql` – Contains 10 SQL aggregation queries.
- `Task_23_Query_Results.md` – Displays the outputs of all queries.
- `Task_23_Query_Results.csv` – Contains summarized query results.
- `README.md` – Project documentation.

## 📊 Key Tasks Performed
1. Counted total orders using COUNT().
2. Calculated total sales using SUM().
3. Calculated average order value using AVG().
4. Identified minimum and maximum order values.
5. Analyzed sales by customer region using GROUP BY.
6. Counted orders by status.
7. Calculated average product prices by category.
8. Analyzed units sold and sales value by product.
9. Calculated monthly sales.
10. Checked NULL values and their behaviour in SQL aggregate functions.

## 📈 Key Learning Outcomes
- Understanding SQL aggregate functions.
- Applying GROUP BY for data summarization.
- Handling NULL values in SQL.
- Generating useful business insights from structured data.

## ▶️ How to Run
1. Download the SQL file.
2. Open MySQL Workbench or PostgreSQL pgAdmin.
3. Create or select a database.
4. Open `Task_23_SQL_Aggregation.sql`.
5. Execute the SQL script.
6. Review the query results.
